# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

The `threed-rs` team takes the security of this software and its dependencies seriously.

If you believe you have discovered a security vulnerability in `threed-rs`, please do **not** open a public issue. Instead, report it privately:

1. Use GitHub's [Private Vulnerability Reporting](https://github.com/eraysevgen/threed-rs/security/advisories/new) on the repository's **Security** tab.
2. Provide detailed steps to reproduce the issue, including example point cloud files or configurations if applicable.

We will acknowledge receipt of your report within 48 hours and work with you to remediate the vulnerability and issue a security release promptly.
